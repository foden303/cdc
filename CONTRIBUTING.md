# Contributing

Thanks for your interest in contributing!

## Getting Started

1. Fork the repo and clone your fork
2. Run `make up` to start dependencies
3. Run `make run` to build and start the service

## Code Style

- **Go** — standard conventions, `gofmt` formatted
- **TypeScript/React** — follow existing patterns, ESLint enforced
- **Protobuf** — Buf style guide
- **Commits** — conventional format: `feat:`, `fix:`, `chore:`, `docs:`

## Pull Requests

1. Branch from `main`
2. Keep changes focused and testable
3. Run `make test` before pushing
4. Open a PR with a clear description

## Questions?

Open an [issue](https://github.com/foden303/cdc/issues).
